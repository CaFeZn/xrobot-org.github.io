# Data Structures

This module summarizes the data structures in LibXR, including queues, stacks, linked lists, red-black trees, double buffers, and more. These structures are designed for use in embedded systems for task scheduling, data communication, and resource management. Each data structure is tailored to its intended use and platform constraints—some are thread-safe, while others adopt lock-free mechanisms for performance optimization. For detailed information, please refer to the respective subpages.
