# ADC（模数转换）

`LibXR::ADC` 提供平台无关的模拟数字转换（ADC）抽象接口，用于读取模拟输入对应的浮点值，适用于电压检测、传感器读取等应用场景。

## 接口定义

```cpp
class ADC {
public:
  ADC() = default;

  // 读取 ADC 浮点值
  virtual float Read() = 0;
};
```

- `Read()` 是纯虚函数，子类需实现具体的采样逻辑；
- 当前基类只约定返回 `float`，并不在接口层统一规定量纲、参考电压或标定方式；
- 在很多平台实现里，这个值通常会被组织成“电压值”，但具体量纲与范围仍取决于具体后端和上层约定；
